# Changelog

## 1.0.0 - 2026-08-07

First public release.

- Citation-verification track with 152 evidence-traceable items in 76 matched fake and real pairs. Every positive is anchored to a court finding with an order URL, hash, page, and short excerpt.
- Constructed document-audit track with 10 scenarios and 196 labeled authority occurrences, plus 18 separately scored memorization probes.
- Deterministic grading and versioned schemas, with resumable OpenAI, Anthropic, Google, DeepSeek, and mock provider adapters for closed-book and standardized CourtListener-assisted conditions.
- Strict provider wire contracts, immutable run and submission receipts, bounded remote and local resources, and retry-inclusive request and input approvals that fail before live inference.
- Aggregate-only submission bundles, a static development leaderboard, and a fresh-history public export with an explicit allowlist and content-hash manifest.
- Reproducible wheel construction, a standard source distribution, pinned dependencies, offline tests, strict type checking, dependency-license review, and manual-dispatch-only Pages deployment.
